# Diplom_2

Автотесты API Stellar Burgers. Дипломный проект Яндекс Практикума.

## Подготовка

- JDK 11.
- Maven 3.9.x.
- Рабочая ветка: `develop2`.

Откройте `pom.xml` как Maven-проект в IntelliJ IDEA и выберите JDK 11.

Проверка сборки:

```sh
mvn clean test
```
