## После первого ревью

Исходные результаты приложены папкой `allure-results/` в корне репозитория.
Аннотации `@Step` исполняются через AspectJ; параметры шагов исключены

Для отчёта из приложенной папки выполните:

```sh
mvn allure:serve -Dallure.results.directory=allure-results
```
